## Version

`git diff v0.9.0 -- src/mcp skill package.json` and `git log v0.9.0..HEAD`:

- No MCP tool and no parameter removed or renamed; none became required. The 18 tools are the same, in the same order.
- Added: optional configPath on terminate_app, open_deep_link, screenshot, swipe, press_key and get_logs; swipe's
  direction (its four coordinates became optional: a direction or all four); scroll_until's within.
- Narrowed: scroll_until's timeoutMs must be non-negative and finite (a negative one ran in 0.9.0); averi.yaml's
  durations are checked at load, and a negative number, which 0.9.0 took, is refused. get_logs' grep and an assert's
  match must compile as a regex, and a cycle among states' detects is a config error: each of these failed in 0.9.0
  too, only later, after the device was touched.
- averi.yaml: new keys (app.ios.keyboardDismiss, a scroll step's within) and a new app.ios.treeSource value, `auto`,
  which is now the default. A comparison of the schema's keys at v0.9.0 and now found none removed.
- The Node engine floor is unchanged (>=20). appium-webdriveragent moved from devDependencies to optionalDependencies,
  so an npm install brings WebDriverAgent where it can. ARCHITECTURE.md no longer ships in the package.

By the runbook's rules the two narrowings are major in letter, and refuse only a timeout that is no budget; the rest
is minor. The version is 1.0.0 because the owner declares the surface stable.

What consumers see change without opting in:

- iOS: a project that names no treeSource gets `auto`: WebDriverAgent when it comes up, idb as a labelled fallback
  (A41a, A72's launch path and tree source).
- A67: an input's text is never quoted, and an input labelled by its own text is said by its length. A54 and A66: a
  refusal or hint after a fill says the typed value by its length, and an assert quotes only its own subject.
- A71: an unknown state, flow or environment name is refused before any device call.
- A73: ensure_state's ⚠ frame line comes before the health line; a verify leg no longer leaves blank lines.
- A76: a within: whose only matches are 0×0 answers absent, in the tap's words.
- get_logs refuses an invalid grep before a device is touched, and an averi.yaml that is present but invalid fails
  every call that reads it, on both platforms.
